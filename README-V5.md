# FLOW FITNESS V5 — Kas Bölgesi Arama

- Egzersiz adı veya hedef kas bölgesiyle Türkçe/İngilizce arama; Türkçe karakter olmadan arama.
- Üst/orta/alt göğüs, ön/arka kol, karın, omuz, sırt, bacak ve kalça filtreleri.
- Ev / Salon filtresi ve isteğe bağlı tüm kas gruplarında arama.
- Kadın / Erkek tercihi cihazda kaydedilir; **mevcut Movement Lab 3D karakterini değiştirmez**. İki ayrı rig/animasyon varlığı eklenmeden model değişimi iddia edilmemelidir.
- 36 mevcut egzersiz korunur. Bütün egzersizlerin birebir 3D animasyonu olduğu iddia edilmez.
- GitHub Desktop ile mevcut flow-fitness klasörüne ZIP içeriğini kopyalayın; `node_modules` klasörlerini aktarmaya gerek yoktur.
